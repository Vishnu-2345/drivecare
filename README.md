# DriveCare - Smart Vehicle Garage & Maintenance Scheduler

A full-stack web application for managing vehicle maintenance, tracking expenses, and scheduling service appointments.

## 🚀 Features

- **User Authentication**: Secure signup/login with JWT
- **Smart Garage**: Add vehicles using VIN auto-lookup (NHTSA API)
- **Expense Tracker**: Log and visualize vehicle expenses with charts
- **Booking System**: Schedule service appointments for your vehicles

## 🛠️ Tech Stack

### Frontend
- React.js with Vite
- Tailwind CSS
- Recharts (Data Visualization)
- React Router
- Axios

### Backend
- Node.js with Express.js
- MongoDB with Mongoose
- JWT Authentication
- bcrypt for password hashing
- NHTSA VIN API Integration

## 📦 Project Structure

```
DriveCare/
├── backend/          # Express API server
└── frontend/         # React application
```
